# Graph Algorithms Visualizer

Windows Forms application for graph creation and Breadth-First Search (BFS) visualization.

## Features

- Create graph vertices
- Create edges
- Prevent duplicate vertices and edges
- Visual graph rendering
- Breadth-First Search traversal
- BFS traversal order output

## Technologies

- C#
- .NET Framework
- Windows Forms
- BFS Algorithm
- Graph Data Structure
